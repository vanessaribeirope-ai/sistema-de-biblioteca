Sistema de Biblioteca
Autora: Vanessa Ribeiro da Silva
Responsabilidades: Projeto desenvolvido individualmente pela autora.
Bibliotecas utilizadas: Nenhuma biblioteca externa, o projeto utiliza recursos do python.
Projeto desenvolvido em Python.
Permite cadastrar, listar, pesquisar, emprestar, devolver e excluir livros.
Também permite consultar a quantidade de livros disponíveis.
Os dados são armazenados no arquivo biblioteca.csv.

Como executar o programa:
1. Acesse o Google Colab pelo navegador.
2. Crie um novo notebook e copie o código do arquivo .py para uma célula de código.
3. Clique no botão de executar da célula para iniciar o programa.
4. Quando o menu aparecer, digite o número da opção desejada e pressione Enter.
5. Para encerrar o programa, escolha a opção 7 - Sair.
