Sistema de Biblioteca
Autora: Vanessa Ribeiro da Silva
Responsabilidades: Projeto desenvolvido individualmente pela autora.
Bibliotecas utilizadas: Nenhuma biblioteca externa, o projeto utiliza recursos do python.
Projeto desenvolvido em Python.
Permite cadastrar, listar, pesquisar, emprestar, devolver e excluir livros.
Também permite consultar a quantidade de livros disponíveis.
Os dados são armazenados no arquivo biblioteca.csv.

Como executar o programa:
1. Acesse o Google Colab pelo navegador.
2. Crie um novo notebook e copie o código do arquivo .py para uma célula de código.
3. Clique no botão de executar da célula para iniciar o programa.
4. Quando o menu aparecer, digite o número da opção desejada e pressione Enter.
5. Para encerrar o programa, escolha a opção 7 - Sair.

Interface gráfica com Gradio
O sistema possui uma interface gráfica desenvolvida com Gradio, permitindo cadastrar, listar, pesquisar, emprestar, devolver e excluir livros, além de contar os disponíveis.
Os dados são armazenados em um arquivo CSV.

Como executar o sistema no Google Colab

1. Baixe os arquivos 'projetofinal_biblioteca.py'  e 'biblioteca.csv' deste repositório.
2. Abra um novo notebook no Google Colab.
3. Envie o arquivo 'biblioteca.csv' para a pasta de arquivos do Colab.
4. Na primeira célula, execute '!pip install gradio'.
5. Na segunda célula, cole o código do arquivo 'projetofinal_biblioteca.py', sem a linha '!pip install gradio', caso ela esteja presente.
6. Execute a célula do projeto. Quando aparecer o menu, digite '7' para abrir a interface Gradio.
7. Utilize os botões para cadastrar, listar, pesquisar, emprestar, devolver e excluir livros.

## Observação: os dados são armazenados no arquivo 'biblioteca.csv'. No Google Colab, as alterações podem ser perdidas ao encerrar a sessão; para preservá-las, baixe o CSV atualizado.
