Sistema de Biblioteca

Autora: Vanessa Ribeiro da Silva
Responsabilidades: Projeto desenvolvido individualmente.
Bibliotecas utilizadas: Nenhuma biblioteca externa, o projeto utiliza recursos do python.
Projeto desenvolvido em Python.
Permite cadastrar, listar, pesquisar, emprestar, devolver e excluir livros.
Também permite consultar a quantidade de livros disponíveis.
Os dados são armazenados no arquivo biblioteca.csv.

 Executar pelo Google Colab (recomendado)

1. Abra o arquivo '.ipynb' no Google Colab.
2. Envie o arquivo 'biblioteca.csv' para a área de arquivos do Colab.
3. Execute a célula de instalação do Gradio.
4. Execute a célula do projeto.
5. Digite '7' no menu para abrir a interface gráfica.
**Não é necessário utilizar o arquivo '.py' quando executar pelo notebook '.ipynb'.**

Interface gráfica com Gradio
O sistema possui uma interface gráfica desenvolvida com Gradio, permitindo cadastrar, listar, pesquisar, emprestar, devolver e excluir livros, além de contar os disponíveis.
Os dados são armazenados em um arquivo CSV.
